## 💡 我相信的工程观
- Agent 从 Demo 到生产的差距不在模型能力，而在模型之外的工程层。
- 一个 10 步任务，即使单步成功率 95%，端到端也只有约 **0.95¹⁰ ≈ 59.9%** —— 所以才需要 Harness。
- 权限不是给 Agent 套的外壳，而是它运行时的原生特性。
